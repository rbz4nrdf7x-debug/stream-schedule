Schedule API v1

This JSON API shares the stream schedule: who is live now, the next stream, and any reschedules or cancellations. All times are ISO 8601 in ET with offset (tz America/New_York).

Static files, read-only, CORS open. Please cache, poll at most once a minute, send a User-Agent that names your agent, and use this API instead of scraping the stream site. The box checks about every 10 minutes and republishes on any change, and at least every 6 hours.

Endpoints (relative to this site)

  • GET v1/schedule.json upcoming streams
  • GET v1/now.json live yes/no, current, next
  • GET v1/changes.json rescheduled (status moved, see new_start) and cancelled
  • GET v1/schedule.ics calendar feed
  • GET v1/health.json treat as stale if generated_at is older than stale_after_sec
  • GET v1/openapi.yaml OpenAPI 3 spec

Per streamer

Query filters do not work on static hosting. Use precomputed files: v1/streamer/{marcus|alex|joint}/schedule.json, now.json, changes.json, schedule.ics. Unknown paths return HTTP 404.

Item

{"id":"marcus-20261025T0900Z","streamer":"marcus","start":"2026-10-25T05:00-04:00",
 "end":"2026-10-25T06:00-04:00","tz":"America/New_York","status":"scheduled","new_start":null,"note":""}

Status: scheduled, live, moved, cancelled. Streamer: marcus, alex, joint (Marcus & Alex).
